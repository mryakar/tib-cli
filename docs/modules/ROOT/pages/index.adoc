= tib
:description: The Idempotent Boilerplate: a scaffolding CLI for Spring Boot services.

tib scaffolds Spring Boot services and adds to them: an entity layer from SQL DDL or a spec, with
its repository, DTO, mapper, service, controller and migration. It runs again on the same project
without breaking anything, and shows what it would change before it changes it. The
https://github.com/mryakar/tib-cli/blob/main/ROADMAP.md[roadmap] says what is done and what comes
next.

== Where to go

* xref:install.adoc[] puts `tib` on your PATH, from the APT repository, a package or a zip.
* xref:getting-started.adoc[] scaffolds the first service.
* xref:spec.adoc[] describes the YAML file that tells tib what to generate.
* xref:ddl.adoc[] says how tib reads the tables of SQL DDL.
* xref:reference/tib.adoc[] lists every command and option, generated from the commands themselves.
