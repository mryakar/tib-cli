= tib
:description: The Idempotent Boilerplate: a scaffolding CLI for Java services, on Spring Boot or in plain Java.

tib scaffolds Java services, on Spring Boot or in plain Java, and adds to them: an entity layer
from SQL DDL or a spec, with its repository, DTO, mapper, service, controller or handler and
migration, and their tests. It runs again on the same service without breaking anything, and shows
what it would change before it changes it. `tib status` says which files were changed since tib
wrote or read them. The https://github.com/mryakar/tib-cli/blob/main/ROADMAP.md[roadmap] says what
is done and what comes next.
