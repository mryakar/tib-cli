= tib
:description: The Idempotent Boilerplate: a scaffolding CLI for Spring Boot services.

tib scaffolds Spring Boot services and adds to them: an entity layer from a DDL or a spec, with
its repository, service, mapper, DTOs, controller and tests. It runs again on the same project
without breaking anything, and shows what it would change before it changes it.

== Status

tib is at the start. `tib init service` scaffolds a Spring Boot 3 service with JPA, PostgreSQL,
Flyway and Testcontainers, from its name or from the xref:spec.adoc[spec file], and `tib generate
entity` adds the entity layer of the spec's entities: entity, repository, DTO, mapper, service,
controller and migration. Both with a real `--dry-run` and a record of what they wrote. The
https://github.com/mryakar/tib-cli/blob/main/ROADMAP.md[roadmap] says what comes next.
