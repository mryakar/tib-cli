= Install
:description: How to install tib on Linux and Windows.

Every package embeds its own Java runtime: nothing else needs to be installed. The packages are on
the https://github.com/mryakar/tib-cli/releases[releases page], with their checksums and signatures.

== Debian and Ubuntu

From the APT repository, which also brings updates with `apt upgrade`:

[source,bash]
----
curl -fsSL https://mryakar.github.io/tib-cli/apt/tib.gpg | sudo tee /usr/share/keyrings/tib.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/tib.gpg] https://mryakar.github.io/tib-cli/apt stable main" | sudo tee /etc/apt/sources.list.d/tib.list
sudo apt update
sudo apt install tib
----

Or from the `.deb` of a release:

[source,bash]
----
sudo apt install ./tib_<version>_amd64.deb
----

Either way, `tib` is in `/usr/bin`, and the application in `/opt/tib`.

== Windows

Run the `.msi` of a release, or install it silently:

[source,powershell]
----
msiexec /i tib-<version>.msi /qn
----

The installer puts `tib` on the PATH of the machine. Open a new console afterwards: a console that
was already open keeps its old PATH.

== Portable zip

For a machine where you cannot install packages: unpack the zip of your platform anywhere, run
`tib/lib/app/startup-cache.sh` on Linux or `tib\app\startup-cache.cmd` on Windows once, so that
tib starts faster, and run `tib/bin/tib` or `tib\tib.exe`. Put that directory on your PATH if you
like.

== Verify a download

The files of a release and the APT repository are signed with this OpenPGP key:

----
4C3A F91B 1B7F 67BD 50D2  8A40 6CCE 0394 9E2A 4A49
----

Each file on the releases page has its signature next to it, with `.asc` added to its name. Take
the key from keys.openpgp.org and check the file against its signature:

[source,bash]
----
gpg --keyserver hkps://keys.openpgp.org --recv-keys 4C3AF91B1B7F67BD50D28A406CCE03949E2A4A49
gpg --verify tib_<version>_amd64.deb.asc tib_<version>_amd64.deb
----

`gpg` reports a good signature and prints the primary key fingerprint above. On Windows, `gpg`
comes with https://gpg4win.org[Gpg4win].

A release also has `checksums_sha256.txt`, signed the same way, with the SHA-256 of every file.
Check its signature, then the files you downloaded against it:

[source,bash]
----
gpg --verify checksums_sha256.txt.asc checksums_sha256.txt
sha256sum --check --ignore-missing checksums_sha256.txt
----

The APT repository needs no step of your own: apt checks every download against `tib.gpg`. To see
that `tib.gpg` holds this key:

[source,bash]
----
gpg --show-keys /usr/share/keyrings/tib.gpg
----

== Check

[source,bash]
----
tib --version
----
